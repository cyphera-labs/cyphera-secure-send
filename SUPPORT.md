# Support

- **Questions and how-to:** open a discussion or an issue with the
  `question` label.
- **Bugs:** open an issue using the bug template. Include the version
  (`cyphera-secure-send --version`), your configuration with secrets removed,
  and the audit or log lines around the problem.
- **Security vulnerabilities:** never in an issue. See [SECURITY.md](SECURITY.md).
- **Commercial support and enterprise features:** hello@cyphera.io.

Documentation lives in [docs/](docs/).
